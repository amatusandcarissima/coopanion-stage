# 用现有骨架拼动作 · 实操手册

> 目标:不画任何新图,只改代码,给她加新动作。
> 全部都在本项目的 `pack\` 里改,改完一条命令装回去。
> 想画新部件/换形象再看 [`动作用什么软件做.md`](动作用什么软件做.md)。

---

## 一、先明白三件事（不然会越改越乱）

1. **她的动作不是视频,也不是序列帧**,是每一帧由 JS 现算出来的一组数字:手臂转多少度、头歪多少、看哪、什么表情。
   内置鲸鲸的 `figure.js` 每帧读一个 `frame` 对象;`whale-stage` 只是在把 `frame` 交给她之前**先改几个字段**(`o.pose`)。
   → 所以"加动作"= 写一段函数,在特定时刻返回不同的数字。

2. **一个动作在三个地方各有一半**:

   | 位置 | 作用 | 不写会怎样 |
   |---|---|---|
   | `figure.json` 的 `vocab` | 让模型认识这个词（她能听懂/说出来、写进她的提示词） | 她能画出这个动作,但你跟她说"挥手告别"她不懂 |
   | `figure.js` 的 `STAGE_WORDS` + `doWord()` | 词被调用时**做什么**(计时多长、进什么姿势、设什么状态) | 词认识但没反应 |
   | `figure.js` 的 `stageFrame()` | 这一段状态下**画成什么样**(手臂/头/表情) | 有反应但看不出动作 |

3. **方向别猜,用预览工具看**。手臂角度这类参数只靠脑补一定翻车（我调 bye 时就把手转到了背后,屏幕上看不见）。

## 二、你手上的零件

- **实测可用的姿势参数**：`armN`(近侧手臂)、`armF`(远侧手臂)、`headTilt`(头歪)、`pitch`(低头/抬头)、`swing`(手臂摆动开关)、`face`(表情)、`look`(视线)。含义见第四节。
- **19 个表情**(直接填 `face` 用)：`neutral happy wink love shy surprised angry sad sleepy thinking smug pout worried determined flustered scared excited cry confused`
- **25 张部件贴图**(`pack\tex\`)：`ahoge arm_far arm_far_end_front arm_near bangs bow brows eye_creases face fin_far fin_near hair_back hair_back_curl hair_front_left hair_front_right headdress leg_back leg_front sidelocks skirt skirt_sit tail torso_up waist_bow_front waist_bow_sit_front`
  → 这些是"参数动画"能用的全部零件;想让腿悬空摆动这种**结构性**动作,得改 `whale.js` 的骨架(第八节)或画新图。
- **原生动作词**(`vocab` 里 23 个 motion)：`stand jump hop look turn nod shake spin sit sleep dizzy walk run wave bow shiver flap dance` + 本包加的 `climbup watchsit typepaw gettup bye`。原生的直接写词就能用,不用自己画。

## 三、30 秒预览循环（最重要的效率工具）

改了姿势先别装进应用 —— 用一个无头浏览器把包挂在"假舞台"上截图看：

```powershell
cd <本项目目录>

# 1) 直接试一组姿势参数(最快,不用改代码)
node tools\preview.mjs --pose '{"armN":80,"armF":-20,"headTilt":4,"pitch":0.2,"face":"happy"}' --scale 2.2 --out t.png

# 2) 一次试多组,自动拼成对照图
node tools\preview.mjs --poses-file .preview\my-poses.json --scale 2.2 --out t.png

# 3) 试动作词本身(看你 doWord 写对没)
node tools\preview.mjs --word bye --scale 2.2 --at 350,700,1050 --out bye.png

# 4) 试落点(看 move 编排对不对)
node tools\preview.mjs --to watch --x 0.5 --y 0.35 --scale 1.1 --hold 2500 --out watch.png
```

- 截图落在项目目录下的 `.preview\`。
- `--scale 1` 是她真实大小;`2.2` 是放大 2.2 倍方便看手。
- 需要 Coopanion 正在运行（它要借宠物服务的 `/packs` 和 `/figure-frame`）,但**不会碰到桌面上的她**。
- **PowerShell 5.1 的坑**：给原生 exe 传含双引号的 JSON 会被吃掉引号。两个办法：
  ① 用 `--pose-file` / `--poses-file` 指向一个 JSON 文件；
  ② 用 node 生成文件再传：
  ```powershell
  node -e "require('fs').writeFileSync('.preview/p1.json', JSON.stringify({armN:80,face:'happy'}))"
  node tools\preview.mjs --pose-file .preview\p1.json --scale 2.2 --out t.png
  ```
- 想看真正装进去后的样子：`npm` 之外的另一条路是 `DEV_AUTOPOSE`（`figure.js` 第 21 行）：改成 `{ to: 'watch', params: [.55, .72] }` → `install.ps1 -PackOnly` → 1.6 秒后她自动执行一次这个 move,截图完再改回 `null`。

## 四、参数手册（这台机器上实测过的方向，不是文档抄的）

| 参数 | 含义 | 方向和量级（实测） |
|---|---|---|
| `armN` | 近侧手臂角度 | **正值 = 往前抬**。`0` 垂在身侧；`+80` 手抬到胸腹前、手心朝前；`>+130` 会转到身后看不见。**负值 = 往后藏**（`-120` 时整条手臂消失在背后） |
| `armF` | 远侧手臂角度 | 符号相反:**负值 = 往前抬**。内置打字姿势用的是 `armN:+42, armF:-38`（两只手都到胸前） |
| `headTilt` | 头歪，单位度 | `±3` 轻歪，`±20` 明显歪；正负是两个方向，先试一次定符号 |
| `pitch` | 低头/抬头 | `+` 低头（脸的部件下移、头顶露出更多），`-` 抬头；范围约 `-1.4～+1.4`，常用 `±0.3` |
| `swing` | 走路时手臂摆不摆 | `0` 锁住不摆（做姿势时都填 0），不填/`1` 跟随走路 |
| `face` | 表情名 | 见上面的 19 个，直接写 |
| `look` | 视线 | `[水平, 垂直]`，量级约 `±4`；`垂直为正 = 往下看` |
| `lean` / `tilt` | 身体前倾/整体左右歪 | 内置姿势用 `±1.5` 级别，幅度很小，配 `headTilt` 用 |

> 这些值都会经过 `whale.js` 里的弹簧（spring）平滑，所以是"目标角度"不是瞬时角度：突然从 0 跳到 100 会有一个 0.2 秒左右的甩过去的过程，这正好是动作"有肉感"的来源。

## 五、三类动作的模板（照抄改）

### A. 一次性手势（做一下就没）—— `bye` 就是这么写的

`figure.js` 里三处：

```js
// ① 词表:告诉 kit 这个词存在、多长
const STAGE_WORDS = {
  ...
  bye: { motion: { seconds: 1.7 } },
};

// ② doWord:被调用时干什么(进状态 + 排一个 done)
if (word === 'bye') {
  const m = mode();
  if (m === 'sit' || m === 'sleep') kitBody.do('stand');
  stage.gesture = { at: stage.clock, dur: STAGE_WORDS.bye.motion.seconds };
  scheduleDone(word, STAGE_WORDS.bye.motion.seconds);
  return true;
}

// ③ stageFrame:这段时间画成什么样
if (g) {
  const k = clamp((t - g.at) / g.dur, 0, 1);      // 0→1 进度
  const env = Math.min(1, k / .15, (1 - k) / .18); // 入场 0.15s / 出场 0.18s 淡入淡出
  const w = Math.sin((t - g.at) * 13);             // 挥手频率
  f.face = 'happy';
  f.look = [o.look[0] * .2, o.look[1] * .2 - 1.2];
  f.pose = { ...(f.pose || {}),
    armN: 10 + (76 + 14 * w) * env,
    armF: -8 - 4 * env,
    headTilt: 1.6 + 1.6 * env + .8 * w * env,
    pitch: .18, swing: 0 };
}
```

再加 `figure.json` 的 `vocab`：

```json
{ "id": "bye", "kind": "motion",
  "names": { "zh": ["挥手告别", "拜拜", "挥手"] },
  "about": { "zh": "抬手来回挥一挥，跟你告别", "en": "raises a paw and waves goodbye" },
  "seconds": 1.7 }
```

→ 装进去之后：`pet_act {actions:["挥手告别"]}`，或直接跟她说"跟我挥手告别"。

### B. 持续姿势（一直保持，直到被打断）—— `watchsit` / `typepaw` 就是

```js
// ① stage 里加一个姿势名(现在是 'watch' | 'type')
if (word === 'peek') { enterPose('peek'); scheduleDone(word, 2.0); return true; }

// ② enterPose 里决定坐下还是站着
function enterPose(kind) {
  stage.pose = kind; stage.poseAt = stage.clock; park();
  const m = mode();
  if (kind === 'watch' || kind === 'peek') { if (m !== 'sit' && m !== 'sleep') kitBody.do('sit'); }
  else if (kind === 'type') { if (m === 'sit' || m === 'sleep') kitBody.do('stand'); }
}

// ③ stageFrame 里加一个分支
} else if (stage.pose === 'peek') {
  const ph = t - stage.poseAt;
  f.face = 'smug';
  f.look = [o.look[0] * .3 + 2.0, o.look[1] * .3 - .8];   // 往右前方偷看
  f.pose = { armN: 62 + 4 * Math.sin(t * 2), armF: -30, headTilt: 6, pitch: -.25, swing: 0 };
}
```

底部要记得:`vocab` 里 `"lasting": true`,`gettup` 负责站起来收势(它调 `exitPose()`)。

### C. 新落点（让她去屏幕上的某个位置）—— `watch/type/near/floor` 就是

1. `figure.json` 的 `moves` 里加一项(参数最多 2 个,`id` 不能叫 `left/center/right/cursor` 或数字)：

```json
{ "id": "peek", "name": { "zh": "去偷看", "en": "peek over there" },
  "about": { "zh": "跑到屏幕某个位置，趴在边沿探头看", "en": "runs there and peeks over the edge" },
  "params": [ { "id": "x", "about": { "zh": "屏幕横向比例 0-1", "en": "horizontal 0-1" }, "min": 0, "max": 1 },
              { "id": "y", "about": { "zh": "落座高度比例 0-1", "en": "perch height 0-1" }, "min": 0, "max": 1 } ] }
```

2. `figure.js` 的 `startMove()` 里把名字接上（现在只认 4 个字符串）：

```js
const targetPose = to === 'watch' ? 'watch' : to === 'type' ? 'type' : to === 'peek' ? 'peek' : null;
```

其余(走位、升降地板、`arrived` 回执、被拖动打断)全部由现有编排处理,不用另写。

> **世界事件里的坐标**：`x = 屏幕像素 / 屏宽`、`y = 落座面像素 / 屏高`（`y=0` 屏幕顶、`1` 屏幕底）。`watch` 用视频画面**底边**的 y 就是"坐在画面下沿"；想站到上沿就传顶边的 y。`y` 别小于 `0.06`（头顶会被屏幕裁掉）。

## 六、装进应用、验收

```powershell
cd <本项目目录>
node --check pack\figure.js            # 语法先过一遍(一个异常她的形象就退回 Coo)
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -PackOnly
```

然后：

- `curl http://127.0.0.1:7797/api/figures/status` → `problems` 必须是空数组（不是空就说明 manifest 不合格，下面会写原因）。
- `/api/figures` 里 `whale-stage` 的 `vocab` 数应该 +1。
- 在应用里试：`pet_act {actions:["挥手告别"]}`，或者跟她说"跟我挥个手告别"。
- 只改 `figure.js` 通常**不用重启**；**改了 `vocab`/`moves` 之后如果她不认识新词,重启一次应用**（`install.ps1 -WorldOnly` 会走重启，或者控制台点重启）。
- 想回到官方鲸鲸：`verify.ps1 -Figure whale`。

## 八、什么时候必须碰骨架 `whale.js`

只做姿势/手势 → 永远不用碰它。要下面这些才需要：

- 腿垂下来晃（现在坐姿只有模型自带的盘腿 `skirt_sit`）
- 尾巴/呆毛独立摆动幅度加大（`whale.js` 里有 `tailMood/finMood/wagAmp` 弹簧）
- 新的关节（比如想让她"躺下"）

改法：`whale.js` 是内置 `figure.js` 的拷贝 + 4 处 `o.pose` 钩子，直接在里面找 `st.armNear = { a: armN }` 这类行，加自己的形变；或者照 [`动作用什么软件做.md`](动作用什么软件做.md) 的 Blender/Aseprite 路线做真动画。注意：**一旦改了骨架，就要自己保证"不传 pose 时行为不变"**，否则她平时的待机动作会跟着变。

## 九、坑清单

| 现象 | 原因 / 解法 |
|---|---|
| 整个形象退回 Coo / 画面空了 | `figure.js` 抛异常(one throw kills the frame)。`node --check`，改完立刻预览；看 `core.log` 里的 `形象包没加载:` 或 `figure.` 开头报错 |
| `problems` 里出现 `vocabNotArray` / `tooNew` | `vocab` 必须是数组；`manifest`、`api` 必须是整数 `2` |
| 新词她听不懂 | ① `vocab` 名字里有空格/逗号/顿号/`【】<>` → 非法；② 名字超过 32 字；③ 同一个名字给了两条词；④ 加了词没重启 |
| 新 move 里 `to` 报"不认识" | `moves` 的 `id` 冲突(左中右/cursor/数字)或超过 8 个；`params` 超过 2 个；改了没重启 |
| 姿势完全没变化 | ① `stageFrame` 早退条件没放行(第 506 行 `if (!stage.pose && !stage.lifting && !g && !stage.devPose) return o`);② 参数给了 0/未传到 `f.pose`;③ 用了 `armN` 但她在朝另一边站(近侧/远侧反了) |
| 预览里改了没效果 | 别忘了 `install.ps1 -PackOnly` —— 预览读的是**已安装副本** `...\data\figures\whale-stage\`，不是源码目录 |
| 手"消失"了 | 角度转到了身后(`armN > +130` 或 `armN < -100`)。调小一个数量级 |
| 包写回去后应用崩 | JSON 里被写进了 BOM（PowerShell 的 `Set-Content -Encoding utf8` 会加）。JSON 一律无 BOM |
| 改了 JS 没生效 | 世界代码要重启应用；形象包只需 `-PackOnly`（每次列包都会重扫），但如果她"不认识词"就重启一次 |
