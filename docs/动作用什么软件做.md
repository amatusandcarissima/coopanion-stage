# 给 Coopanion 的形象做动作:用什么软件,怎么落地

这份文档回答两件事:**Coopanion 的动画到底是怎么动的**(这决定了能用什么软件),
以及**你想做的动作该用什么工具、按什么步骤做成**。

先给结论:

| 你想要的效果 | 推荐软件 | 为什么 |
|---|---|---|
| 只给现在的鲸鲸加动作(坐、看、打字、爬) | **不用新软件**,直接写 `figure.js` 的参数动画 | 鲸鲸已经是"参数驱动"的 Live2D 式骨架,动作是代码,不是关键帧文件 |
| 想自己画新形象 / 新部件 | **Krita**(免费)或 Clip Studio Paint / Photoshop | 需要"一个部位一个图层、全画布透明 PNG" |
| 想要专业的关键帧手感,又不想手写曲线 | **Blender**(免费)烘焙成数字 JSON,再由 JS 回放;或用 **Spine 2D / DragonBones 的纯 JS 运行时**内联进包 | 沙箱里能跑 JS,但**不能用 wasm**;Spine 运行时需要你自己有授权 |
| 想要逐帧的"手绘感"(比如 12 帧的挥手) | **Aseprite** / Krita 时间轴 / CSP 动画 | 导出 PNG 序列,JS 按时间换图 |
| 只做参考、找手感 | **Live2D Cubism**(免费版)、Rive | 可以拿来试绑定,但**工程文件不能直接用**(它们依赖 wasm),只能把满意的参数抄成 JS 数字 |

---

## 1. 先搞懂:Coopanion 的动作是"代码"不是"视频"

一个形象包(figure pack)就两样东西:

1. **图片**:每个身体部位一张**全画布透明 PNG**(内置鲸鲸是 1086×1448 的整张画布,
   每个部件都在同样的画布位置,叠起来才是完整的人)。
2. **`figure.js`**:一段 JS,每帧(默认 120fps 上限)拿到一组状态数字,
   算出每个部位应该旋转多少、位移多少、缩放多少,然后画出来。

内置鲸鲸(`web/whale/`)用的是**自己写的 Live2D 式变形**:把每张部件贴图铺到网格(rig)上,
用 `rot`(旋转)和 `warp`(网格弯曲)两种变形器分层驱动,头发/尾巴/鳍/手臂上挂了弹簧,
所以跑起来有惯性和回弹。不是 Spine、不是 Live2D、不是 Rive——是 3000 行手写 WebGL。

每帧交给 `figure.draw(petG, face, frame)` 的 `frame` 里有(节选):

| 字段 | 含义 |
|---|---|
| `facing` | 朝向 -1 / 1 |
| `mode` | stand / walk / run / sit / sleep / drag … |
| `modeT` | 当前模式已经持续多久 |
| `talk` | 说话的嘴型幅度 0..1 |
| `look` | 眼睛看向的方向(鼠标) |
| `legs` | 走路时双腿的相位 |
| `tilt` / `lean` | 整体倾斜、前倾(拖拽、急停时用) |
| `lookDown` / `low` | 低头量、蹲低量 |
| `sit` | 坐下程度 0..1(坐下时腿会换贴图) |
| `blink` / `eyeClose` | 眨眼 |
| `swing` | 摆动(悬挂时) |
| `gesture` | 当前动作词 + 进度 `{kind, k}`,k 从 0 到 1 |

**所以"做动画"= 写一个函数,把上面这些数字映射成部件参数。** 这也是为什么
"Spine / Live2D / Rive 的工程文件不能直接用":它们的运行时要么联网、要么 eval、
要么播放 video/audio,而形象包运行在一个 **CSP 极严的沙箱 iframe** 里:

- `default-src 'none'`,`connect-src 'none'` → 不能 fetch、不能 ws;
- 只能加载**图片**(而且只能来自宠物本地服务、`data:` 或 `blob:`);
- **不能加载视频、音频、字体**;
- 包总大小上限 128 MB,首次加载 20 秒内完成;
- `api: 2` 的 kit 是冻结的,内置文件升级会覆盖。

## 2. 路线 A(推荐,也是这次给鲸鲸加动作用的):参数动画

### 2.1 只加动作、不画新图

现有鲸鲸的部件(`tex/`:手臂、鳍、尾巴、头发、裙摆、腿……)已经够拼出很多动作:
坐下、翘腿、挥手、探头、打字(前臂小幅上下)、趴着看、回头看、伸懒腰……

做法:

1. 在 `figure.json` 的 `vocab` 里加词条(名字会直接进她的提示词):
   ```json
   { "id": "typepaw", "kind": "motion", "names": { "zh": ["打字", "敲键盘"] },
     "about": { "zh": "两只手在键盘上敲", "en": "tapping paws on a keyboard" },
     "seconds": 2, "lasting": true }
   ```
   规则:`names.zh` 里**不能有空格、逗号、顿号、全角括号、`<` `>` `【` `】`**,每个名字 ≤32 字符,
   id 和所有名字在全诗包内唯一;`lasting: true` 表示"一直保持到下个动作"。
2. 在 `figure.js` 里给她画这个动作:要么在 `figure.draw()` 里按 `frame.gesture.kind` 分支,
   要么(更简单)把新动作加进 figure 的 `gestures` 数组,让她在 `draw` 里根据 `k` 算参数。
3. 切到你的形象包,`pet_act {actions:["打字"]}` 试一次;不对就改数字,刷新即见。

### 2.2 想画新部件/新形象

推荐 **Krita**(免费、开源,Windows 支持好)。要点:

- **一张母版画布**,所有部位都画在同一张画布上,**一个部位一个图层**;
- 导出时每个图层都导成**全画布尺寸**的透明 PNG(不要裁切到内容边界!内置鲸鲸就是全程 1086×1448);
- 图层顺序 = 叠放顺序(后画的盖前面),部件之间的遮挡关系靠多画几份"被挡住的部分"解决;
- 需要切分旋转轴时,用内置鲸鲸那套做法:把某个部件先涂成纯洋红(色键)导出,再和正常版做差分,得到"这个部件遮住了谁"的遮罩;
- 文件命名和 `model.json` 里的部件 id 对应起来。

替代品:Clip Studio Paint(付费,笔刷和网点更舒服)、Photoshop(付费,图层/智能对象方便)、
Procreate(iPad)。三者导出流程一样。

### 2.3 调动作手感

- 关节旋转用**弹簧**:`v += (target - x) * k * dt - v * damping * dt`,k 越大越硬;
- 呼吸/待机用 `sin(t * 2π / 3)` 这种很慢的周期;
- 说话嘴型用 `talk` 直接驱动嘴部贴图的缩放;
- 眨眼用随机间隔 + 80ms 的快速闭合曲线。

## 3. 路线 B:用"专业动画软件"做曲线,再烘成数字

如果你不想手写曲线,想让软件里拖关键帧:

1. **Blender**(免费,推荐):
   - 把每个部件当平面导入(`Images as Planes`),一张图一个对象;
   - 用骨骼/空物体绑成木偶(父子关系即可,不需要复杂绑定);
   - 在时间轴上摆姿势、打关键帧;
   - 导出:把每帧每个部件的旋转/位移/缩放烘成数字,存成 JSON
     (Blender 的 Python 脚本:`bpy` 遍历 `frame_range`,把 `matrix_world` 拆成 2D 的 x/y/角度写进 JSON);
   - `figure.js` 读这个 JSON(可以用 `import` 静态引入,或让页面用 `asset()` 给 URL),
     按当前时间插值回放。
2. **After Effects + DUIK Bassel**(付费):2D 木偶绑定更专业,
   用脚本(ExtendScript)把每个图层每帧的 `position/rotation/scale` 导出成 JSON,流程同上。

**关键限制:只能导出数字,或"纯 JS 运行时 + 数据文件"。** 不要想着导出视频或序列帧贴图视频——
沙箱里放不了;`.riv`(Rive)和 `.model3.json`(Live2D)依赖 **wasm**,沙箱里也加载不了。

补充:Spine / DragonBones 的**纯 JS 运行时可以内联进包**(它们是解释 `.json`/`.skel` 数据的 JS,
不需要 wasm,也不联网),所以严格说"Spine 工程能进包"——前提是你把运行时和授权一起带上,
并且把 JSON 也放进包里。这条路线比自己手写参数动画重,但专业关键帧的手感是现成的。

## 4. 路线 C:逐帧序列(最快出"手绘感")

适合:挥手、蹦一下、表情包式的夸张动作。

1. 用 **Aseprite**(像素风)或 **Krita / CSP 的时间轴**画 8–24 张 PNG;
2. 文件名 `action-000.png`…,放进包目录(比如 `anim/`);
3. `figure.js` 里 `loadImage()` 预载所有帧,`draw()` 里按 `(t * fps) % frames` 换图;
4. 注意体积:1086×1448 RGBA 每张几百 KB,24 张约 10 MB,可接受(上限 128 MB);
   也可以把单张裁到动作实际占的范围再拼,但位置要自己记住偏移。

逐帧和参数动画可以混用:身体用参数,手部小动作用几帧序列。

## 5. 参考和验证工具(不是做动画用的)

- **OBS Studio / ScreenToGif**:录一段真人/参考视频,逐帧看动作节奏;
- **Live2D Cubism(免费版)**:想先试试"这个姿势好不好看"可以拿它绑定一下找手感,
  但**文件不能进包**,只能把满意的角度数字抄回 JS;
- **Rive / Spine**:同上,只作参考。生态里唯一能"真用 Live2D"的是另一个世界
  `cortico-world-vtuber`(它接的是 VTube Studio,一个外部程序,不是形象包)。

## 6. 一次完整的上线流程(以"打字"动作为例)

1. **想清楚**:她坐在输入框下沿,两只前臂交替小幅上下,头微微点,眼睛看输入框。
2. **改 `figure.json`**:加词条 `typepaw`(见 2.1),`seconds: 2`,`lasting: true`。
3. **改 `figure.js`**:在 `draw()` 里根据 `frame.gesture.kind === 'typepaw'` 或一个
   "坐姿 + 打字相位"的状态,驱动 `arm_near` / `arm_far` 的旋转、`brows` 的轻微下压。
4. **本地试**:把包放进 `<数据目录>\home\companion\figures\<你的包id>\`,
   宠物服务的 `/api/figures` 会立刻列出它;`/api/skin` 切换或用换装页点一下。
5. **调数字**:截图对比、改弹簧参数,直到不穿模。
6. **让别人也能用**:把整个包目录压成 zip,在换装页「导入」;
   包里必须有 `figure.json`,`id` 不能和内置的 `coo` / `whale` 重名。

## 7. 常见坑

- **相对路径 import 会失败**:形象包在 `/packs/<id>/` 下,只能用绝对路径,
  比如 `import { createBody } from '/web/kit/body.js'`;`../kit/body.js` 不行。
- **一个异常就换回内置 Coo**:`figure.js` 的异常会让整个帧死掉,页面退回 Coo。
  先 `try/catch` 把错误打出来。
- **vocab 名字限制**:不能带空格/标点/全角括号,否则整个词条被丢弃;
  `vocab` 字段缺失会让**整个包**不被加载。
- **`manifest: 2` / `api: 2` 必须是整数**,写成字符串会被拒。
- **不要改内置包**:升级会覆盖。要改就复制成自己的包(这次的 `whale-stage` 就是这么做的)。
- **`needs: ["windows"]` 只能拿到窗口顶边的几何**(没有标题、进程名),
  想让动作"知道屏幕在发生什么",得靠 World 扩展(见下一条)。
- **形象包不能联网、不能读窗口、不能读键盘**。要做"用户在看视频/在打字"这种感知,
  只能写在 **World 扩展**里(这次的 `cortico-world-stage` 就是干这个的):
  World 负责"看见",然后通过提示词让 Coo 自己调用 `pet_move_to`。
